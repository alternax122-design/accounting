# 血壓記錄 Power BI 建置說明

資料：`血壓資料.csv`（2026/1/1–9/30，共 499 筆讀數，長表格式）
主題：`血壓主題.json`（米白＋陶土橘，沿用專案風格）

| 欄位 | 說明 |
|---|---|
| 日期 | yyyy-mm-dd（115 年 = 2026 年） |
| 時段 | 早／晚 |
| 收縮壓、舒張壓 | mmHg |
| 脈壓差 | 收縮壓 − 舒張壓（由程式計算，非逐筆抄寫） |
| 脈搏 | 次/分 |
| 體重 | kg，紙本多半只在晚上記錄，空白 = 沒記 |
| 備註 | 看診、旅遊等 |

## 1. 匯入
1. 取得資料 → 文字/CSV → 選 `血壓資料.csv`（檔案原始檔 65001 UTF-8）→ 轉換資料。
2. 欄位型別：日期＝日期、收縮壓/舒張壓/脈壓差/脈搏＝整數、體重＝小數、其餘＝文字 → 關閉並套用。
3. 檢視 → 佈景主題 → 瀏覽佈景主題 → 選 `血壓主題.json`。

## 2. 行事曆資料表（建模 → 新增資料表）
```DAX
行事曆 =
ADDCOLUMNS (
    CALENDAR ( DATE ( 2026, 1, 1 ), DATE ( 2026, 9, 30 ) ),
    "月份", MONTH ( [Date] ),
    "月份名稱", FORMAT ( [Date], "M月" ),
    "星期", WEEKDAY ( [Date], 2 )
)
```
把 `行事曆[Date]` 拉到 `血壓資料[日期]` 建立一對多關聯；`月份名稱` 以 `月份` 排序。

## 3. 量值
```DAX
平均收縮壓 = AVERAGE ( 血壓資料[收縮壓] )
平均舒張壓 = AVERAGE ( 血壓資料[舒張壓] )
平均脈壓差 = AVERAGE ( 血壓資料[脈壓差] )
平均脈搏   = AVERAGE ( 血壓資料[脈搏] )
平均體重   = AVERAGE ( 血壓資料[體重] )
量測次數   = COUNTROWS ( FILTER ( 血壓資料, NOT ISBLANK ( 血壓資料[收縮壓] ) ) )

偏高次數 =
COUNTROWS ( FILTER ( 血壓資料, 血壓資料[收縮壓] >= 135 || 血壓資料[舒張壓] >= 85 ) )

偏高比例 = DIVIDE ( [偏高次數], [量測次數] )
```
135/85 是居家量測的常用高血壓切點，可依醫師建議調整。

## 4. 建議視覺效果（單頁版面）
1. **卡片列**：平均收縮壓、平均舒張壓、平均脈搏、偏高比例、平均體重。
2. **折線圖「血壓趨勢」**：X＝日期（連續）、Y＝收縮壓、舒張壓（平均）、圖例＝時段；分析窗格加兩條常數線 135、85。
3. **折線圖「脈搏」**：X＝日期，Y＝脈搏，圖例＝時段。
4. **折線圖「體重」**：X＝日期，Y＝體重（只有有記錄的日子會連線）。
5. **群組直條圖「月平均」**：X＝月份名稱、Y＝平均脈壓差，圖例＝時段。
6. **矩陣（熱度圖）**：列＝月份名稱、欄＝時段、值＝平均收縮壓，條件式格式設定用色階。
7. **散佈圖**：X＝舒張壓、Y＝收縮壓、詳細資料＝日期，圖例＝時段。
8. **資料表**：日期、時段、收縮壓、舒張壓、脈壓差、脈搏、體重、備註。
9. **切片器**：日期（區間）、時段。

## 5. 資料備註
- 空白格 = 當天沒量，不是 0。
- 4 月紙本第 31 列有一筆 141/95、脈搏 98（4 月只有 30 天），已略過。
- 1/22 晚上體重寫作 64（其他日子約 66–68），可能是 66.4 的筆誤，請核對。
- 手寫數字有些潦草，請在匯入後抽查幾筆與紙本對照。
